================================================================================
🐛 TROUBLESHOOTING
================================================================================

Error: "Studi kasus tidak ditemukan" (masih terjadi setelah run SQL)
---------------------------------------------------------------------
Solution:
1. Check apakah SQL sudah benar-benar ter-execute:
   - Run query: SELECT * FROM case_studies WHERE id IN ('case-1', 'case-2', 'case-3');
   - Harus return 3 rows
   
2. Jika tidak ada data:
   - Check connection string POSTGRES_URL di Vercel
   - Pastikan pointing ke database yang benar
   
3. Clear browser cache dan refresh

Error: "Failed to load resource: 404" di console
---------------------------------------------------------------------
Solution:
1. Check Vercel deployment status
2. Wait 1-2 minutes untuk deployment selesai
3. Refresh page

Error: "Database connection failed"
---------------------------------------------------------------------
Solution:
1. Check POSTGRES_URL di Vercel environment variables
2. Check database status di Neon.tech dashboard
3. Restart database jika suspended
