═══════════════════════════════════════════════════════════
TROUBLESHOOTING
═══════════════════════════════════════════════════════════

Problem: HTTP 400 masih muncul
Solution:
1. Clear cache browser HP
2. Force reload (Ctrl+Shift+R atau clear data)
3. Coba browser lain (Chrome/Firefox)
4. Restart HP

Problem: "Failed to fetch"
Solution:
1. Matikan firewall SEMENTARA
2. Test lagi dari HP
3. Kalau berhasil = allow Node.js di firewall
4. Nyalakan firewall lagi

Problem: Backend tidak bisa start
Solution:
1. Pastikan port 3002 tidak dipakai:
   netstat -ano | findstr :3002
2. Kalau ada, kill process atau ganti port
3. Edit server/.env: PORT=3003
4. Edit .env: VITE_API_URL=http://192.168.1.10:3003/api
5. Restart

Problem: Test 1,2,3 gagal semua
Solution:
Backend tidak bisa diakses dari HP
→ Cek firewall (paling sering)
→ Cek WiFi sama
→ Restart router
