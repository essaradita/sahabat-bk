📋 PERSIAPAN SEBELUM DEPLOY
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

✅ 1. SETUP DATABASE POSTGRESQL
   
   Pilih salah satu:
   
   Option A - NEON (Recommended - Gratis):
   ┌─────────────────────────────────────────────────────────────┐
   │ 1. Buka https://neon.tech                                   │
   │ 2. Sign up / Login                                          │
   │ 3. Klik "Create Project"                                    │
   │ 4. Pilih region terdekat (Singapore)                        │
   │ 5. Copy "Connection String"                                 │
   │    Format: postgresql://user:pass@host/db?sslmode=require  │
   └─────────────────────────────────────────────────────────────┘
   
   Option B - SUPABASE:
   ┌─────────────────────────────────────────────────────────────┐
   │ 1. Buka https://supabase.com                                │
   │ 2. Sign up / Login                                          │
   │ 3. Klik "New Project"                                       │
   │ 4. Settings > Database > Connection String                  │
   │ 5. Copy connection string                                   │
   └─────────────────────────────────────────────────────────────┘

✅ 2. IMPORT DATABASE SCHEMA
   
   ┌─────────────────────────────────────────────────────────────┐
   │ File: database/schema_postgres.sql                          │
   │                                                             │
   │ Cara import:                                                │
   │ - Neon: Buka SQL Editor > Paste > Run                      │
   │ - Supabase: SQL Editor > Paste > Run                       │
   └─────────────────────────────────────────────────────────────┘

✅ 3. GENERATE JWT SECRET
   
   ┌─────────────────────────────────────────────────────────────┐
   │ Di terminal (Git Bash / WSL):                               │
   │                                                             │
   │ $ openssl rand -base64 32                                   │
   │                                                             │
   │ Copy hasilnya, contoh:                                      │
   │ kR9mN2pQ5vX8zB1yC4wF7tH0jL3sA6eD9gK2mP5nQ8rT1vU4xY7   │
   └─────────────────────────────────────────────────────────────┘

🎯 LANGKAH DEPLOY KE VERCEL
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

✅ STEP 1: PUSH KE GITHUB

   $ git add .
   $ git commit -m "Migrate to Vercel full-stack serverless"
   $ git push origin main

✅ STEP 2: CONNECT KE VERCEL

   1. Buka https://vercel.com
   2. Login dengan GitHub
   3. Klik "Add New Project"
   4. Pilih repository "sahabat-bk"
   5. Klik "Import"

✅ STEP 3: CONFIGURE PROJECT

   Framework Preset:     Vite
   Root Directory:       ./
   Build Command:        npm run build
   Output Directory:     dist
   Install Command:      npm install

   ⚠️  JANGAN KLIK DEPLOY DULU!

✅ STEP 4: TAMBAH ENVIRONMENT VARIABLES

   Klik "Environment Variables" tab
   
   Tambahkan 2 variables ini:
   
   ┌─────────────────────────────────────────────────────────────┐
   │ Name:  POSTGRES_URL                                         │
   │ Value: postgresql://user:pass@host/db?sslmode=require      │
   │        (paste connection string dari Step 1)                │
   └─────────────────────────────────────────────────────────────┘
   
   ┌─────────────────────────────────────────────────────────────┐
   │ Name:  JWT_SECRET                                           │
   │ Value: (paste JWT secret dari Step 3)                       │
   └─────────────────────────────────────────────────────────────┘
   
   Pilih environment: Production, Preview, Development (semua)

✅ STEP 5: DEPLOY!

   Klik "Deploy" dan tunggu 2-3 menit ☕
   
   Progress akan muncul:
   - Building...
   - Functions detected...
   - Deployment ready!

🐛 TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

❌ Error: "POSTGRES_URL not found"
   → Cek Environment Variables di Vercel
   → Redeploy: Deployments > ... > Redeploy

❌ Error: "Database connection failed"
   → Pastikan connection string benar
   → Cek database masih aktif di Neon/Supabase
   → Pastikan ada ?sslmode=require di akhir URL

❌ Error: "Token tidak valid"
   → Logout dan login ulang
   → Clear browser cache (Ctrl+Shift+Delete)
   → Cek JWT_SECRET sudah ada di Vercel

❌ Frontend blank / tidak muncul
   → Cek console browser (F12)
   → Cek Vercel Functions logs
   → Redeploy project
