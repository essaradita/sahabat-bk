CARA 3: MANUAL PAKAI CMD (100% PASTI JALAN)
═══════════════════════════════════════════════════════════

Step 1: Backend
───────────────
1. Tekan Windows + R
2. Ketik: cmd
3. Enter
4. Di CMD, ketik (satu per satu, tekan Enter):

   cd "C:\Users\ASUS\SAHABAT BK\server"
   npm start

5. Tunggu sampai muncul "Server berjalan..."
6. JANGAN TUTUP window ini!

Step 2: Frontend
────────────────
1. Tekan Windows + R lagi
2. Ketik: cmd
3. Enter
4. Di CMD baru, ketik (satu per satu, tekan Enter):

   cd "C:\Users\ASUS\SAHABAT BK"
   npm run dev:hp

5. Tunggu sampai muncul "Network: http://192.168.1.10:5174"
6. JANGAN TUTUP window ini!

Step 3: Buka di HP
──────────────────
Browser HP → http://192.168.1.10:5174

═══════════════════════════════════════════════════════════
❌ TROUBLESHOOTING
═══════════════════════════════════════════════════════════

Problem: File .bat langsung tutup
─────────────────────────────────
Penyebab:
- Node.js belum terinstall
- Folder server tidak ada
- Path salah

Solusi:
1. Cek Node.js terinstall:
   - Buka CMD
   - Ketik: node --version
   - Harus muncul versi (contoh: v18.17.0)
   - Kalau error: Install Node.js dari nodejs.org

2. Cek folder:
   - Pastikan file .bat ada di folder "SAHABAT BK"
   - Di dalam harus ada folder "server"

3. Pakai CARA 3 (manual dengan CMD)

Problem: "npm not found"
────────────────────────
Solusi:
1. Install Node.js dari: https://nodejs.org
2. Restart PC
3. Coba lagi

Problem: Load Failed di HP
──────────────────────────
Solusi:
1. Cek backend jalan (ada window CMD?)
2. Cek frontend jalan (ada window CMD?)
3. PC dan HP WiFi yang SAMA
4. Coba akses dari PC dulu: http://192.168.1.10:5174

Problem: IP Address salah
─────────────────────────
Solusi:
1. Buka CMD
2. Ketik: ipconfig
3. Lihat "IPv4 Address" (contoh: 192.168.1.15)
4. Edit .env:
   - Buka dengan Notepad
   - Ubah: VITE_API_URL=http://192.168.1.15:3002/api
   - Save
5. Restart backend & frontend
