========================================
🔍 TROUBLESHOOTING
========================================

❌ MASALAH: Soal tidak tersimpan
SOLUSI:
- Buka Console browser (F12)
- Tab "Network"
- Coba save soal lagi
- Cari request: "questions"
- Status harus 200, bukan 404/500
- Jika 404 → Deployment belum selesai, tunggu lagi
- Jika 500 → Ada error di server, cek Vercel logs

❌ MASALAH: Siswa tidak lihat soal baru
SOLUSI:
- Pastikan guru sudah klik "PUBLIKASIKAN" (bukan cuma Simpan Draft)
- Siswa HARUS refresh halaman (Ctrl+F5)
- Cek console browser siswa, lihat error apa

❌ MASALAH: Loading terus menerus
SOLUSI:
- Tunggu 10 detik
- Jika masih loading → Ada error API
- Cek console browser (F12) → Tab "Console"
- Screenshot error, kirim ke developer

❌ MASALAH: Vercel deployment failed
SOLUSI:
- Klik deployment yang failed
- Scroll ke bawah, lihat error log
- Biasanya: environment variable kurang
- Cek POSTGRES_URL dan JWT_SECRET sudah diset
