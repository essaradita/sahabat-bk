🔎 ANALISA MASALAH:

ROOT CAUSE:
- Fungsi handleDelete() hanya menghapus dari state React (useState)
- Data tidak tersimpan ke database
- Saat refresh, data dimuat dari demoClasses yang masih utuh

KODE LAMA (SALAH):
```javascript
function handleDelete(id) {
  setClasses(prev => prev.filter(c => c.id !== id))  // Hanya hapus di state
  toast('Kelas berhasil dihapus', 'info')
  // ❌ Tidak ada API call ke backend!
}
```

MASALAH BACKEND:
- Table 'classes' belum dibuat di SQLite
- API endpoints untuk class management belum ada
- Frontend tidak bisa menyimpan perubahan

═══════════════════════════════════════════════════════════════

✅ SOLUSI YANG DITERAPKAN:

1. ✅ TAMBAH TABLE DI DATABASE
   File: server/db-sqlite.js
   - Ditambahkan table 'classes' dengan kolom:
     * id (primary key)
     * name (nama kelas)
     * grade (tingkat 7-9)
     * teacher_name (wali kelas)
     * teacher_id (foreign key)
     * student_count (jumlah siswa)
     * created_at, updated_at (timestamp)

2. ✅ TAMBAH API ENDPOINTS DI BACKEND
   File: server/server.js
   - GET    /api/teacher/classes → Ambil semua kelas
   - POST   /api/teacher/classes → Buat kelas baru
   - PUT    /api/teacher/classes/:id → Update kelas
   - DELETE /api/teacher/classes/:id → Hapus kelas
   
   Semua endpoint:
   • Dilindungi dengan verifyToken
   • Cek role teacher
   • Error handling lengkap
   • Console logging untuk debugging

3. ✅ TAMBAH API METHODS DI FRONTEND
   File: src/lib/api.js
   - apiClient.getClasses()
   - apiClient.createClass(data)
   - apiClient.updateClass(id, data)
   - apiClient.deleteClass(id)

4. ✅ UPDATE FRONTEND COMPONENT
   File: src/pages/teacher/ManageClasses.jsx
   
   A. Tambah useEffect untuk load dari database:
      ```javascript
      useEffect(() => {
        async function fetchClasses() {
          const data = await apiClient.getClasses()
          setClasses(data)
        }
        fetchClasses()
      }, [])
      ```
   
   B. Update handleSave() untuk simpan ke database:
      ```javascript
      async function handleSave() {
        if (editingClass) {
          const result = await apiClient.updateClass(id, form)
          setClasses(prev => prev.map(c => c.id === id ? result.class : c))
        } else {
          const result = await apiClient.createClass(form)
          setClasses(prev => [result.class, ...prev])
        }
      }
      ```
   
   C. Update handleDelete() untuk hapus dari database:
      ```javascript
      async function handleDelete(id) {
        await apiClient.deleteClass(id)  // ✅ Hapus dari database
        setClasses(prev => prev.filter(c => c.id !== id))
        toast('Kelas berhasil dihapus', 'success')
      }
      ```
   
   D. Tambah loading state:
      ```javascript
      if (loading) {
        return <Loader2 /> // Spinner saat loading
      }
      ```
