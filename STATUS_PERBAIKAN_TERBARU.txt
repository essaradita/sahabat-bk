🔍 DEBUGGING TIPS:

Jika masih error, cek hal berikut:

1. BACKEND HARUS JALAN
   • Cek terminal backend ada tulisan "Server running on port 3002"
   • Test buka: http://localhost:3002/api/health
   • Harus muncul: {"status":"OK"}

2. FRONTEND HARUS JALAN
   • Cek terminal frontend ada tulisan "ready in ... ms"
   • Browser Console (F12) → tidak ada error merah

3. DATABASE CONNECTION
   • File database.sqlite harus ada di folder server/
   • Ukuran file harus > 0 KB (tidak kosong)

4. BROWSER CACHE
   • Pastikan sudah hard refresh (Ctrl+Shift+R)
   • Coba buka di Incognito/Private mode

Saat test Bank Soal, di Console (F12) akan muncul:
