═══════════════════════════════════════════════════════════════

🔎 ROOT CAUSE:

FILE: src/layouts/TeacherLayout.jsx

KODE LAMA (SALAH):
```jsx
<aside className={`
  fixed lg:static inset-y-0 left-0 z-40 w-64
  ...
`}>
```

MASALAH:
• `lg:static` membuat sidebar jadi static di desktop
• Static artinya sidebar jadi bagian dari document flow
• Ketika scroll, sidebar ikut ke-scroll

═══════════════════════════════════════════════════════════════

✅ SOLUSI:

PERUBAHAN 1: SIDEBAR TETAP FIXED
--------------------------------
BEFORE:
```jsx
<aside className="fixed lg:static ...">
```

AFTER:
```jsx
<aside className="fixed ...">
```

• Sidebar sekarang `fixed` di semua ukuran layar
• Tidak ikut scroll
• Selalu di posisi kiri layar

PERUBAHAN 2: TAMBAH MARGIN KE MAIN CONTENT
------------------------------------------
BEFORE:
```jsx
<div className="flex-1 flex flex-col min-w-0">
```

AFTER:
```jsx
<div className="flex-1 flex flex-col min-w-0 lg:ml-64">
```

• `lg:ml-64` = margin-left 256px (lebar sidebar)
• Konten tidak tertutup sidebar
• Konten dimulai setelah sidebar

PERUBAHAN 3: TAMBAH shrink-0 KE HEADER & FOOTER
-----------------------------------------------
BEFORE:
```jsx
<div className="p-5 border-b border-blue-700">
<div className="p-3 border-t border-blue-700">
```

AFTER:
```jsx
<div className="p-5 border-b border-blue-700 shrink-0">
<div className="p-3 border-t border-blue-700 shrink-0">
```

• `shrink-0` mencegah header/footer mengecil
• Header & footer tetap tingginya
• Hanya bagian nav yang scrollable

🎨 CSS CLASSES YANG DIPAKAI:

SIDEBAR:
• `fixed` - Posisi fixed (tidak scroll)
• `inset-y-0` - Top: 0, Bottom: 0 (full height)
• `left-0` - Posisi di kiri
• `z-40` - Z-index tinggi agar di atas konten
• `w-64` - Width 256px

MAIN CONTENT:
• `lg:ml-64` - Margin-left 256px di desktop
• `overflow-y-auto` - Konten bisa scroll vertikal

SIDEBAR SECTIONS:
• `shrink-0` - Tidak mengecil (header & footer)
• `flex-1` - Flexible size (nav area)
• `overflow-y-auto` - Nav bisa scroll jika terlalu panjang
