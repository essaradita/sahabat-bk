🚀 CARA DEPLOY (RINGKAS):

Ikuti 6 langkah mudah:

1️⃣  PUSH KE GITHUB (5 menit)
    • git init
    • git add .
    • git commit -m "Initial commit"
    • Buat repo di GitHub
    • git push

2️⃣  DEPLOY BACKEND KE RENDER (10 menit)
    • Buat account render.com (gratis)
    • Connect GitHub repo
    • Set environment variables
    • Add persistent disk untuk database
    • Deploy!

3️⃣  UPDATE API URL (2 menit)
    • Edit .env.production
    • Edit src/lib/api.js
    • Commit & push

4️⃣  DEPLOY FRONTEND KE VERCEL (5 menit)
    • npm install -g vercel
    • vercel login
    • vercel --prod

5️⃣  UPDATE CORS (3 menit)
    • Tambah Vercel URL ke CORS
    • Commit & push
    • Render auto-deploy

6️⃣  TEST PRODUCTION (5 menit)
    • Buka website
    • Test login
    • Test CRUD
    • Done! 🎉
