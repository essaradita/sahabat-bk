================================================================================
🐛 TROUBLESHOOTING
================================================================================

Error: "Misi tidak ditemukan" (masih terjadi setelah run SQL)
---------------------------------------------------------------------
Solution:
1. Verify data dengan query: SELECT * FROM missions;
2. Pastikan ada 6 rows dengan ID mission-1 sampai mission-6
3. Clear browser cache (Ctrl+Shift+Delete)
4. Refresh halaman (Ctrl+F5)

Error: "Popup berhasil muncul tapi data tidak berubah"
---------------------------------------------------------------------
Solution:
1. Buka Browser Console (F12 → Console tab)
2. Lihat apakah ada error merah
3. Kemungkinan:
   - API endpoint gagal (check Vercel logs)
   - Data tidak ter-refresh (perlu hard refresh Ctrl+F5)
   - Database connection issue (check POSTGRES_URL)

Error: "Siswa tidak lihat mission yang ditambah guru"
---------------------------------------------------------------------
Solution:
1. Pastikan status mission = 'active' (bukan 'draft')
2. Refresh halaman siswa (Ctrl+F5)
3. Check di database: SELECT * FROM missions WHERE status='active';
4. Pastikan mission_id format: 'mission-X' atau 'mission-timestamp'

File: database/seed_missions.sql

INSERT INTO missions (id, title, description, category, difficulty, world_id, xp_reward, coin_reward, estimated_minutes, status)
VALUES 
  ('mission-1', 'Detektif Emosi', 'Kenali berbagai emosi...', 'pribadi', 'mudah', 'world-1', 20, 50, 10, 'active'),
  ('mission-2', 'Minat dan Bakatku', 'Temukan apa yang kamu sukai...', 'pribadi', 'mudah', 'world-1', 20, 50, 12, 'active'),
  ('mission-3', 'Manajemen Waktu', 'Belajar mengatur waktu...', 'pribadi', 'sedang', 'world-1', 25, 60, 15, 'active'),
  ('mission-4', 'Konflik Teman Sebaya', 'Cara menyelesaikan pertengkaran...', 'sosial', 'mudah', 'world-2', 20, 50, 10, 'active'),
  ('mission-5', 'Kekuatan Empati', 'Memahami perasaan orang lain...', 'sosial', 'sedang', 'world-2', 25, 55, 12, 'active'),
  ('mission-6', 'Anti Bullying', 'Memahami bahaya bullying...', 'sosial', 'sedang', 'world-2', 30, 70, 15, 'active')
ON CONFLICT (id) DO UPDATE SET
  title = EXCLUDED.title,
  description = EXCLUDED.description,
  ... (update semua field)

NOTE: ON CONFLICT DO UPDATE artinya:
- Jika ID sudah ada → UPDATE (tidak error, tapi update data)
- Jika ID belum ada → INSERT (tambah baru)
Ini berguna untuk re-run script tanpa error duplicate.
