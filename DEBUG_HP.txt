STEP 4: CEK FIREWALL WINDOWS
═══════════════════════════════════════════════════════════

Kadang Windows Firewall block koneksi dari HP.

A. Cek Status Firewall:
   
   1. Start → "Windows Defender Firewall"
   2. Klik "Allow an app through firewall"
   3. Cari "Node.js"
   4. Pastikan centang "Private" DAN "Public"

B. Kalau Node.js tidak ada dalam list:
   
   1. Klik "Allow another app..."
   2. Browse ke: C:\Program Files\nodejs\node.exe
   3. Add
   4. Centang Private & Public
   5. OK

C. Restart Backend & Frontend

STEP 7: CEK ERROR DI CONSOLE
═══════════════════════════════════════════════════════════

Di HP browser (Chrome):

1. Buka: http://192.168.1.10:5174
2. Ketuk menu (3 titik) → "Desktop site" (centang)
3. Ketuk menu → "Inspect" atau "Developer Tools"
4. Tab "Console"
5. Coba login
6. Lihat error apa yang muncul

Common Errors:

• "Failed to fetch" / "Network error"
  → Backend tidak bisa diakses
  → Cek firewall

• "Unexpected token '<'"
  → Backend mati / tidak jalan
  → Restart backend

• "ERR_CONNECTION_REFUSED"
  → Port salah atau backend mati
  → Cek port di CMD window

• "404 Not Found"
  → API URL salah
  → Cek .env
