📋 LANGKAH-LANGKAH:

1. PASTIKAN WiFi SAMA
   ✓ PC dan HP harus terhubung ke WiFi yang sama
   ✗ Jangan pakai hotspot HP

2. START BACKEND
   - Klik 2x: start-backend.bat
   - Tunggu sampai muncul: "Server berjalan di..."
   - JANGAN TUTUP window ini!

3. START FRONTEND  
   - Klik 2x: start-frontend-hp.bat
   - Tunggu sampai muncul: "Local: ... Network: ..."
   - JANGAN TUTUP window ini!

4. AKSES DARI HP
   - Buka browser di HP
   - Ketik: http://192.168.1.10:5174
   - Login sebagai Guru atau Siswa

═══════════════════════════════════════════════════════════

⚠️ TROUBLESHOOTING:

Problem: "Load Failed" di HP
Solution:
  1. Cek backend jalan (ada window "Server berjalan"?)
  2. Cek frontend jalan (ada window "Network: ..."?)
  3. Coba akses dari PC dulu: http://192.168.1.10:5174
  4. Jika PC bisa, HP tidak: Cek WiFi sama atau tidak

Problem: IP Address berubah
Solution:
  1. Buka CMD, ketik: ipconfig
  2. Cari "IPv4 Address" (contoh: 192.168.1.15)
  3. Edit file .env, ganti IP lama dengan IP baru:
     VITE_API_URL=http://192.168.1.15:3002/api
  4. Restart backend & frontend

Problem: Firewall Block
Solution:
  1. Buka "Windows Defender Firewall"
  2. Click "Allow an app through firewall"
  3. Cari "Node.js" atau "npm"
  4. Centang "Public" dan "Private"
  5. Restart backend & frontend
