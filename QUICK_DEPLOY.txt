⚠️  TROUBLESHOOTING:

ERROR: "Failed to fetch"
→ Backend sleep, tunggu 30-60 detik first request
→ Atau setup keep-alive cron (KEEP_ALIVE_CRON.md)

ERROR: "CORS blocked"
→ Cek CORS origin di server/server.js
→ Tambahkan Vercel URL

ERROR: "Database kosong"
→ Cek disk mount path di Render
→ Harus: /opt/render/project/src/server
